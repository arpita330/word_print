# Gift Card Generator Bot

A Telegram bot and web application for generating beautiful gift cards with custom codes.

## Features

- 🤖 Telegram Bot with commands
- 🎨 Web-based gift card generator
- 📱 Real-time preview
- 💾 Download as PNG images
- 🔒 Input validation
- ☁️ Deployable to Vercel

## Setup

### Prerequisites

- Node.js 18+
- Telegram Bot Token (from [@BotFather](https://t.me/BotFather))
- Vercel account (optional)
